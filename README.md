
# artistic-engineering
a project I am creating with the idea of combining an many artistic mediums I can with engineering related skills!


Project description: A decoration that is a flower with a butterfly. The butterfly is 3d modelled and printed to house 2 servo motors, which will control the wing flapping motion. The wing motion will be triggered via a hall sensor underneath a petal. The butterfly will contain a magnet, allowing the hall sensor to pick it up. Also, the petals are reinforced with a thick wire so the magnet should cause the butterfly to rest on the flower without any external help. I am using the analog output on the Arduino, as I only need the hall threshold to be over a certain number. Additionally, the stamens (I think that's what they're called) will be wired up to leds controlled by the same hall sensor, so once the magnitized butterfly is brought close enough the middle of the flower will light up.
